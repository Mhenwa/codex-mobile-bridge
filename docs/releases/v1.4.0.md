# v1.4.0 · Mhenwa Connect

这是 `Mhenwa/codex-mobile-bridge` 的首次正式发行，包含 Windows、macOS 和 Linux 桌面安装包。

## 本次更新

- 合并上游 v1.4.0，保留 Mhenwa Connect 的中继连接与账号接入功能。
- 加入 Web Push，支持在手机关闭网页后接收已关注聊天的通知；实际送达取决于浏览器、系统权限与推送服务的网络可达性。
- 修复 Windows 打包程序的 HTTPS 根证书加载，兼容包含中文等 Unicode 字符的证书路径，保持证书与主机名校验。
- 修复 Linux 打包验证的配置，x64 与 ARM64 安装包均通过 CI 构建和运行检查。
- 恢复删除首页的“管理账号与切换接入”快捷按钮；账号管理可从左侧“账号与接入”进入。

五个平台的安装包均来自通过验证的同一次 CI 构建。

## 下载与安装

| 平台 | 提供的安装包 |
| --- | --- |
| Windows x64 | `Setup.exe` 安装版、ZIP 便携版 |
| macOS Apple Silicon / ARM64 | DMG、ZIP |
| macOS Intel / x64 | DMG、ZIP |
| Linux x64 / amd64 | DEB、AppImage |
| Linux ARM64 | DEB、AppImage |

请下载对应平台的文件。`SHA256SUMS.txt` 提供各安装包及固定文件名副本的 SHA-256 校验值。

本次发行需手动下载安装。升级前先停止网关，并从托盘菜单退出旧 App；保留原数据目录，安装后继续使用该目录以保留配置和登录数据。升级后重新加载手机页面。

本次不提供签名的 `bridge-update.json` 更新清单，因此暂不支持通过 App 内的“应用更新”自动升级到此版本。

## 平台说明

- Windows 安装包没有代码签名证书，系统可能显示未知发布者提示。
- macOS 安装包采用 ad-hoc 签名，尚未经过 Apple 公证。
- Linux 支持仍为实验性，已验证 x64 与 ARM64 的 DEB 安装和 AppImage 运行。
